# Mini Aventura

Site do carrinho elétrico infantil, com valor anunciado de **R$ 513,00** e botões que direcionam para o Mercado Livre.

- Site público: https://mini-aventura-carrinho.empresa-con.chatgpt.site/
- Compra: https://meli.la/17dg6pX

## Arquivos

O site completo está em `dist/`, incluindo `index.html` e as quatro imagens em `assets/`.

É um site estático, sem dependências e sem etapa de compilação. Abra `dist/index.html` no navegador ou use `dist` como diretório de publicação em uma hospedagem estática.
